# Для Claude

Сайт материалов фестиваля: https://teatr.idealcontinent.org (после деплоя, см. deploy/DEPLOY.md).
Чтобы опубликовать готовый материал: положить Markdown в `content/<раздел>/<материал>.md` (имена латиницей,
первая строка `# Заголовок`, для нового раздела `_title.txt` с русским названием), закоммитить и запушить.
Сервер подтягивает репозиторий `git pull` каждые 5 минут. Домен из облачной сессии недоступен, проверить страницу можно локально (README).
