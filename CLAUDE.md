# Для Claude

Сайт материалов фестиваля: https://teatr.idealcontinent.org (после деплоя, см. deploy/DEPLOY.md).
Чтобы опубликовать готовый материал: положить Markdown в `content/<раздел>/<материал>.md` (имена латиницей,
первая строка `# Заголовок`, для нового раздела `_title.txt` с русским названием), закоммитить и запушить.
Разделов два: `content/1-gotovye-sceny/` (готовые тексты сцен) и `content/2-predlozheniya/` (списки вариантов
для разработки). Порядок задаёт номер в начале имени файла. На сайт идёт только чистовой текст: без пометок
«уточню/сверить», планов, чек-листов и списков «чего не хватает».
Сервер проверяет GitHub каждые 5 минут и при изменении кода сам перезапускается. Домен из облачной сессии недоступен, проверить страницу можно локально (README).
