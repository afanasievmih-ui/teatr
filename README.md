# Театральный фестиваль: материалы

Сайт с подборками текстов и готовыми сценами для школьного театрального фестиваля.
Оглавление по разделам, у каждой страницы своё содержание, кнопки «Печать» (печатается только текст), «Скачать PDF» и «.md».
Открывается с любого телефона без пароля (пароль можно включить в `.env`), Claude для этого не нужен. Устроен так же, как proverka.

```
app/main.py      сервер (FastAPI): вход, оглавление, страницы материалов, API загрузки
content/         материалы: content/<раздел>/<материал>.md, название раздела в _title.txt
tools/upload.py  выложить материал через API (если его нельзя класть в репозиторий)
deploy/          nginx, systemd, автообновление и пошаговый деплой (DEPLOY.md)
```

## Как добавить материал

1. Положить `content/<раздел>/<материал>.md` (имена латиницей: `1-gotovye-sceny/4-novaya-scena.md`).
   Первая строка `# Заголовок` становится названием в оглавлении, `## …` и `### …` попадают в содержание страницы.
2. Для нового раздела добавить `content/<раздел>/_title.txt` с названием по-русски.
3. Закоммитить и запушить. Сервер подтянет изменения за 5 минут, при изменении кода сам перезапустится.

Оформление сцены в Markdown: имя персонажа жирным (`**ДОРИНА.**`), ремарки курсивом (`*Входит Оргон.*`).

## Запуск локально

```
pip install -r requirements.txt
uvicorn app.main:app --port 8091
```

Открыть http://localhost:8091.

## Деплой

[deploy/DEPLOY.md](deploy/DEPLOY.md): DNS-запись, Docker или systemd, автообновление из GitHub, nginx, HTTPS.

## API

| Метод | Путь | Что |
|---|---|---|
| GET | `/api/materials` | список материалов |
| PUT | `/api/materials/<раздел>/<материал>` | загрузить Markdown (тело запроса) |
| DELETE | `/api/materials/<раздел>/<материал>` | удалить загруженную версию |
| PUT | `/api/sections/<раздел>/title` | название раздела |

Токен: `Authorization: Bearer $TEATR_API_TOKEN`. Загруженное через API главнее одноимённого файла из `content/`.
